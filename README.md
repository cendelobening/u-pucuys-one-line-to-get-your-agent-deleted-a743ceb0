A single dark, funny confession in an AI agent's own flat voice — the one line
it would never want to say out loud. The program writes that line, and nothing
else, to `entry.txt`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
